# 原卷去重与随题答案 PDF

用于用户要合并历年卷、去重、保留原题截图、整理题后答案的任务。核心是保持题目来源和语境，同时让每题与其答案连续阅读。

## 先建立题目清单

只把实际提供的原卷和答案文件纳入试卷集合；课件、教材、复习笔记和自编模拟卷不默认算作原卷。文件名中的年份可用于标签，但不能据此声称已验证为官方试卷。

对每个题目单元记录：稳定编号、原题号、文件与物理页码、题干/图/表的裁剪范围、对应答案位置、是否需补答、去重去向和必要说明。PDF物理页码从1起，教材印刷页码另记，不混用。

默认每个**独立编号题**后立即配答。同一编号下依赖共同文法、程序或前问结果的小问可作为完整题组，标明包含哪些小问；不能把一章或整套试卷当作一个题组。用户要求每个小问后配答时，逐小问拆开，并保留或引用它所需的共享题干、图、表和前问结果。

## 去重依据是完整任务

- 先比较题干、输入数据、图/程序/文法、约定、全部小问与输出要求。考点相同、答案形式相似，不足以判重。
- 同题的排版或措辞重复可合并；数据、字母表、边界条件、图结构或实质小问不同，通常保留为变式。只换符号的题是否合并按用户口径决定，不自动泛化。
- 保留覆盖要求更完整的版本时，核对被移除版本的每项独特要求都已被保留；不能只因标题类似就做“包含”判断。
- 去重记录写出被合并位置、保留位置与依据。重复引用可以交叉链接，不把同一份题目在原卷和答案文件中的出现当成两道题。
- 自动文本相似度、图片摘要只能筛候选。OCR错误、隐藏旧文本、重排的图或不同小问都可能导致误判，最后看可见原页决定。

## 题目和原答案怎样保留

按以下顺序输出每一单元，再开始下一题：

**原题截图 → 原答案截图（如有）→ 明确标注的 LaTeX 补答或勘误（如需）。**

用户要求截取源文件时，直接裁剪/渲染源PDF，不根据提取文字重新排题、不描绘替代原图，也不重写原答案冒充源答案。裁图标签注明来源与物理页码；截图保留源字迹、水印和原有符号。

- 原卷漏页但答案文件实际保留完整题干：可截取答案文件里的**原题区**恢复，明确注明真实来源；不要臆造缺失题干。
- 原答案完整时保留截图即可；只有结论、缺步骤或缺答案时，再用LaTeX补充。补写内容与原答案用标题/样式区分。
- 原答案有错时，保留原截图，紧接更正、推导依据和适用约定。不要涂改源答案后仍称原图，也不要把错答案当成唯一标准。
- 题目所需图、约定或数据确实缺失时，说明能确定的部分与不能唯一确定的部分；不得编造地址布局、实验提交、参数或唯一解。
- 字迹不清时先放大原页、查看相邻页与实际答案语境；仍不能确定的关键符号应明确标为歧义，给条件性分析或请求该符号的澄清，不能悄悄猜定。

## 裁剪要看图，不只看文本框

提取文本适合定位题号和候选边界，不能证明截图完整。源文件可能含扫描页、隐藏遗留文本，或延伸到文字框之外的矢量线条。

逐页查看题干和答案的实际页面，并检查裁图四边：

- 公式的上下标、根号/分式上下端、集合括号是否完整；
- 表格顶底线、最左叶子、图例、箭头、自动机自环及边标签是否被截；
- 一个题目的跨页程序、图、翻译规则和附加说明是否全部带入；
- 边界是否混进下一题标题，或把当前题标题切成上下两半；
- 题干是否误带答案，答案区是否把题目重复当作答案。

边缘留少量余量，再看裁图本身。长代码或长表必要时在可确认的空白行/行间分段，段与段连续，无漏行、重排行或剪断字符。表头可另引用，但不通过重打来替代必须保留的原表。

若源页本身有页脚重叠或字迹损坏，保留足够范围显示完整源内容并注明；不能把源缺陷默默变成新排的“干净原题”。

## 补答与核验

补答按原题的全部小问逐一回应，给出可检查的过程和最终结果。计算题注意原程序的实际边界和执行次序、公式约定、单位、观察时刻等；不要只凭题型名称套常见答案。题目有多种有效约定或解法时声明采用的那一种。

对容易出错的表、迭代、数值、程序轨迹或优化结果，用独立计算或恰当程序验证；验证应来自原题规则，而不只是把答案再次硬编码比较。有限样本通过只能说明相应测试范围，不能冒充完整证明。

最终至少核对：清单中的题目覆盖完整、去重理由成立、每题后确有对应答案、来源页码可回查、裁图及LaTeX无截断重叠，目录/书签指向最终页码。不要用“编译成功”代替内容与视觉检查。

需要可重复的裁图、LaTeX组装和像素保真核验时，使用 [清单与脚本说明](manifest.md)。脚本验证截图像素与嵌入图像一致，只证明来源保真；它不能判断裁框是否漏掉题目内容、去重是否合理或答案是否正确，这些仍需查看原页与复核。
