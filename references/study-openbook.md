# 复习讲义与开卷速查

按用户的实际用途选一种产物，或组合其明确需要的部分；不要默认同时交付讲义、速查册和模拟卷。

| 用途 | 阅读方式 | 优先保证 |
|---|---|---|
| 学习型复习讲义 | 顺着概念和例题学习 | 基础解释、解题步骤、完整算例、自测与答案 |
| 开卷查阅资料 | 带着题目快速定位 | 索引、条件、公式与操作模板、例题页码 |
| 已有基础的考前压缩版 | 用短时间查漏补缺 | 易错条件、题型检查点、错题回练 |

## 先对齐材料与范围

- 清点课件、教材版本、课堂例题、往年卷及参考答案；区分教师材料、学生笔记和网络整理。
- 建立“课程主题 → 课件位置 → 教材章/节 → 已出现题型”的映射。不同教材章节号不通用，不能把参考书章号写成课程章号。
- 明确课件当前发布到哪里。未发布、未见到或尚未讲授的章节，不自动等于“不考”；需要补充的内容标出依据与待校准处。
- 年份、题型与分值只根据实际拿到的卷面统计。开卷、闭卷、考试时长或课程版本不同的样本分开解释，不用频次推出“必考/不考”。
- 若用途、页数限制或允许携带的资料形式会改变成稿，应尽早简短确认；同时继续清点材料、提取目录与核对来源，不因非关键偏好停工。没有限制时按可读性与内容量决定篇幅，不凭空承诺页数。

## 学习型讲义

围绕“看懂对象 → 学会步骤 → 独立完成题目”组织，而不是照抄课件目录。

每个核心题型按需要包含：

1. **基础与符号**：先说明对象、术语、输入输出和前置知识，再给公式。首次学习者需要解释符号的含义；已有基础时可压缩。
2. **可执行步骤**：给出每步做什么、何时停止、如何检查结果。不要只写算法名或结论。
3. **完整算例**：展示关键中间量、表格、推导或计算，说明为什么这样做；有多种约定时先声明本例采用哪一种。
4. **易错条件**：聚焦会改变答案的边界、单位、符号约定、假设和例外，不堆泛泛提醒。
5. **自测与答案**：题目能脱离正文独立作答，答案与评分/检查点可分开阅读；自编题明确标注，不冒充历年真题。

复习优先级依据实际题型覆盖、前置依赖和用户薄弱点安排。将“考试高频”“基础但样本未直接考”“后续课件待确认”区分清楚；不要为了压缩篇幅删掉解题必需的基础。

需要完整模拟卷时，核对总分、各小问分值、参考答案评分之和与建议时间。没有被要求时，不为凑齐产物额外生成一套模拟卷。

## 开卷速查

### 先确认真正影响设计的约束

了解已知的页数/纸张上限、单双面、是否允许电子文件或搜索、是否允许批注，以及考试中最常查什么。用户已给出的约束直接沿用；没有相关限制时不自行编造考试规则。

### 用两条入口组织

- **按概念查**：目录、关键词与常见别名指向相应页；相近符号或容易混淆的概念放在一起比较。
- **按题型查**：从题目给定信息出发，指向“适用方法 → 操作步骤 → 完整例题 → 检查点”。索引页码以最终编译结果为准。

每张公式/方法卡只放考试中有用的内容：名称、定义或公式、符号/单位、成立条件、选择该方法的线索、停止准则或结果检查，以及对应例题页码。不能把适用条件省掉后只留一行公式。

复杂方法可采用“一页操作模板 + 后页完整算例”；需要判断条件的题型可用短决策表。常用常数、变换约定、正负号、上下标、边界情况和查表规则应紧邻其用途，不散落在远处。

### 按实际查阅方式排版

- 纸质版使用清楚的分区、稳定页眉和页码；双面打印时检查内外边距与翻页后定位。颜色仅作辅助，黑白打印仍能辨认层级。
- 电子版保留可搜索正文、可点击目录和书签。数学符号的关键词可用可搜索文字作邻近说明；不要承诺截图里的字天然可搜索。
- 原题截图保真与可搜索速查是不同需求：截图留在真题部分，必要时另做关键词/题型索引；不要为搜索而偷偷重排用户要求保真的题目。
- 不能把全部课件缩进极小字号来满足页限。先删重复叙述、合并索引和压缩空白，再取舍低优先级材料；页限与可读性冲突时明确说明取舍。

## 成稿检查

抽取用户实际会遇到的几个题型或关键词，试着从目录/索引定位，确认不用通读整册才能找到方法。检查公式是否带必要条件、例题引用是否正确、答案能否重算，以及表格、图形和代码跨页后是否仍可读。

数学与计算部分采用适合题目的独立复算、单位/量纲检查、数值例或程序验证；有限枚举不当作一般证明。参考答案与程序语义冲突时，应说明依据并更正，而不是选择看起来更像标准答案的一方。

可从 [讲义模板](../assets/handout.tex) 或 [开卷速查模板](../assets/openbook.tex) 起步；根据用途删改结构。数学公式进入标题时给书签一个纯文字版本，例如使用 `\texorpdfstring{数学标题}{文字标题}`，再核对最终PDF导航。

若任务还包含原卷汇编，转读 [原卷与随题答案](source-papers.md)，不要将两种正文组织方式混在一起。
